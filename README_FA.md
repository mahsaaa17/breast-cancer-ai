# فایل‌های رابط کاربری پروژه سرطان پستان

## فایل‌های موجود
- `app.py`: برنامه Streamlit برای دریافت CSV و نمایش پیش‌بینی مدل.
- `requirements.txt`: وابستگی‌ها با نسخه‌های مشخص.
- `sample_input.csv`: پنج ردیف نمونه با ۳۰ ویژگی ورودی (بدون ستون تشخیص).

## فایل ضروری که باید خودتان اضافه کنید
فایل مدل دانلودشده از Colab را با نام دقیق `breast_cancer_rf.joblib` در همین پوشه قرار دهید.

## ساختار مخزن GitHub
```
Breast_Cancer_AI/
├── app.py
├── requirements.txt
├── sample_input.csv
└── breast_cancer_rf.joblib
```

## اجرای محلی/ابری
Streamlit Community Cloud از مخزن GitHub و فایل `app.py` به‌عنوان نقطه ورود استفاده می‌کند. در مرحله ساخت برنامه، مخزن، شاخه `main` و مسیر `app.py` را انتخاب کنید.

**هشدار:** این برنامه صرفاً یک نمونه آموزشی است، ابزار تشخیص پزشکی نیست و نباید با داده‌های هویتی یا پرونده واقعی بیمار استفاده شود.
